核心物理
CORE PHYSICS

所有读数由解析式实时求解，不用查表、不做近似。

C = ε₀·εᵣ·S / d
01电容 · CAPACITANCE
C = ε₀ εᵣ Sd
S 固定、介质不变时 C 与 d 成反比；d 减半，C 翻倍。
02场强 · FIELD
E = Vd = Qε₀ εᵣ S
恒压时 E 随 d 反比变化；恒电荷时 E 与 d 无关。
03位移反演 · INVERSION
Δx = d₀( C₀C − 1 )
小位移下 ΔC/C₀ ≈ −Δx/d₀，把电容变化还原为位移。

三步完成实验

建议按顺序操作，观察读数与曲线的同步变化。

STEP 01 · 改变板距

拖动左侧 板间距 d 滑块，或直接拖动剖面图中的上极板。观察 C 如何随 d 反向变化；开启“恒电荷”后再看 E 是否改变。

STEP 02 · 更换介质

点击 PTFE / 玻璃 / 陶瓷，观察 εᵣ 增大时 C 成比例增大。固定 d 时，C 与 εᵣ 是线性关系。

STEP 03 · 微位移反演

进入“位移传感”，用 Δx 滑块模拟器械尖端移动（单步 1 µm）。比较设定位移与反演位移，并记录至少 3 组数据。
